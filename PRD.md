# PRD (Dokumen Spesifikasi Produk) - BRIGHT SPACE

## 1. Ringkasan Eksekutif

- **Nama Proyek**: BRIGHT SPACE
- **Target Pengguna**: Siswa Sekolah Dasar
- **Tujuan Platform**: Portal web pembelajaran interaktif EdTech yang dioptimalkan khusus untuk perangkat sekolah berspesifikasi rendah (RAM 2GB–4GB).

## 2. Spesifikasi Teknologi & Lingkungan

- **Bahasa & Framework**: PHP Native, Vanilla JavaScript
- **Desain & Styling**: Tailwind CSS (via CDN)
- **Kontrol Versi**: Git & GitHub (`https://github.com/Alfath-mh/Coding-web-kids.git`)
- **Server Lokal**: XAMPP (`D:\Xampp\htdocs\Competition`)

## 3. Identitas Visual & Tema ("Pastel Cosmic")

- `bg-cosmic`: #E0F2FE (Biru Langit Lembut)
- `card-cosmic`: #EDE9FE (Ungu Pastel Muda)
- `accent-cosmic`: #FEF3C7 (Kuning Bintang Warm)
- `text-cosmic`: #1E1B4B (Indigo Gelap Deep Space)
- **Tipografi**: Nunito / Fredoka (Gaya font yang Ramah Anak)

## 4. Tahapan Pengembangan (Kerangka Kerja J-E-L-A-S)

- **Sub-Tahap 2A**: Penyiapan Layout Awal & Header Melayang (Sticky Header) Tema Cosmic.
- **Sub-Tahap 2B**: Perulangan PHP `foreach` untuk Grid 4 Kartu Planet Mata Pelajaran.
- **Sub-Tahap 2C**: Modal Kuis Interaktif & Antarmuka Gamifikasi (Star Coins).
